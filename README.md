# 3Dサイコロ回転デモ

ブラウザで `index.html` を開くと起動します。サーバーやライブラリのインストールは不要です。

## 操作方法

- スマートフォンでは、画面上を上下左右のいずれかにフリックします。
- PCでは、マウスの左ボタンを押して上下左右のいずれかにドラッグし、ボタンを離します。
- 24ピクセル以上の移動で、最も大きく動いた方向にサイコロが90度回転します。
- 回転は約300ミリ秒で終わり、次の面が正面を向きます。回転中に始めた操作は無視されます。

## 遊び方

- 上、左、下、右の順に、サイコロが1個ずつ近づきます。出現時の中央の目を除いた5種類からランダムに選ばれます。同じ方向にすでにサイコロがあると、その列の外側に付きます。
- 中央に直接接していて、中央と同じ目のサイコロが消えます。一致判定の対象は各方向の列の先頭1個です。星が光の尾を引いて画面の外へ流れます。
- 次のサイコロを置く場所が画面に収まらなくなるとゲームオーバーです。原因になったサイコロが画面端にピンク色で残ります。右下の「リトライ」で最初から遊べます。
