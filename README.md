# korokoro サイコロゲーム by michi-303

ブラウザで `index.html` を開くと起動します。サーバーやライブラリのインストールは不要です。

## 操作方法

- 画面をタップするかキーを押すと、Ready、GO! の表示に続いてプレイが始まります。
- スマートフォンでは、画面上を上下左右のいずれかにフリックで90ど回転します。
- PCでは、上下左右の矢印キーを押すか、マウスで上下左右にドラッグで回転します。

## 遊び方

- 上、左、下、右の順に、サイコロが1個ずつ近づきます。出現時の中央の目を除いた5種類からランダムに選ばれます。同じ方向にすでにサイコロがあると、その列の外側に付きます。
- 中央から各方向に同じ目が連続している分をまとめて消します。コンボ数には中央も含まれます。上下左右を含む5コンボ以上で全消しになります。星が光の尾を引いて画面の外へ流れます。
- 次のサイコロを置く場所が画面に収まらなくなると「Game Over」と表示されます。原因になったサイコロが画面端にピンク色で残ります。表示の3秒後から、画面のタップかキー入力で最初から遊べます。
- ゲームオーバー画面では、原因となったドロップを含む直前の最大8ドロップを繰り返し再生します。ゲームオーバー時の盤面は、再生を始める前に毎回5秒間表示します。
